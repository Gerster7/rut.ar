# rut.ar

rut.ar es una plataforma web que conecta operadores Logísticos con
Fleteros. Los Logísticos publican cargas que necesitan transporte y
pueden buscar y asignar Fleteros. Los Fleteros, por su parte, pueden
explorar las cargas disponibles y postularse a realizarlas. El sistema
sugiere candidatos ordenados por proximidad geográfica e historial,
reduciendo el tiempo de búsqueda manual y minimizando los kilómetros
recorridos sin carga.
